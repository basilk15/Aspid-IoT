baudtide

Give every device a clearer signal.

BaudTide is AspidIoT's open-source Linux serial workspace for ESP32, Arduino, and USB/TTY devices. It runs the whole bench, compares live and recorded telemetry, searches every capture, and carries a safe view onto your iPhone.

Open-source ambition

Tools for the bench should belong to the community using them.

BaudTide is our contribution to the greater IoT community: a public, inspectable workspace for the everyday work between a board, a serial line, and the engineer trying to understand what just happened.

01Build in public

Let the roadmap, issues, and implementation stay visible to the people building with connected hardware.

02Keep the signal local

Capture raw device output on the machine where the work is happening, with exports when the team needs them.

03Make contribution easier

Give embedded developers a focused starting point for testing, observing, and extending the serial workflow.

What ships inside

One workspace for the whole serial loop.

From the first port discovery to the final exported log, BaudTide keeps embedded debugging readable and close to the device.

01CONNECT

Meet the device at the port.

Discover USB and TTY ports or enter a path manually, reuse recent device settings, tune serial framing, and let automatic reconnect watch for a board that drops away.

Auto-discovery / manual paths / recent profiles / auto-reconnect

02WORKSPACE

Run the whole bench in one workspace.

Keep several devices open in independent tabs or tiled views, preserve per-device settings, and save named layouts you can return to later.

Multiple devices / tab + tile views / saved layouts / session restore

03READ + SEND

Control the stream without losing the capture.

Pause, filter, search, or clear the visible terminal while raw logging continues, then send text or exact hexadecimal bytes with session-specific line endings and display encoding.

Non-destructive display controls / text + hex / timestamps / encoding

04ANALYZE + REPLAY

Compare live behavior with what happened before.

Detect repeatable telemetry in nested JSON, key/value, CSV, and TSV streams; align live sessions with saved captures; then overlay, replay, window, and export the fields that matter.

Live + capture comparison / independent or overlay views / CSV + JSON export

05CAPTURE + FIND

Search the capture library, not just its filenames.

Every terminal writes to a raw local log. Filter captures by state, search metadata and captured content, preview or save a copy, reopen a log in Visualize, or reconnect with its original setup.

Local raw logs / indexed content search / preview / reopen / save copy

06SHARE + CONTROL

Put a read-only signal window on iPhone.

Scan a same-network link to open live telemetry and raw output on iPhone or another phone, share or download logs, and expose remote text or hex commands only when the desktop operator explicitly enables them.

iPhone-ready companion / QR pairing / read-only default / revocable control
