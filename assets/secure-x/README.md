# Secure-X mark

The current Secure-X product mark is `secure-x-mark-v3.png`. Its concept and generation prompt are documented in [the product marks guide](../PRODUCT_MARKS.md). Earlier marks are retained.

`secure-x-mark.png` was generated with the built-in image generation tool for the pricing page. It has a transparent background. The existing Auth-X logo and Tunnel-X emblem were supplied as family style references.

Final prompt:

> Use case: logo-brand  
> Asset type: standalone Secure-X product mark for web UI, transparent PNG.  
> Input images: Image 1 is Auth-X brand reference, which has connected paths and terminal points; Image 2 is Tunnel-X brand reference, which has luminous blue X material. Create a distinct sibling mark, not a recolor or copy of either.  
> Subject: a compact X made from TWO continuous engineered security paths. Each path is a clean rounded ribbon with a visible terminal point at opposite corners, meeting in a small crisp central diamond junction. The crossing should convey identity and protected data joined. Strong silhouette with enough negative space to read at 40px. Balanced square icon, centered.  
> Style: restrained premium enterprise identity, vector-friendly geometry, crisp edges, shallow cyan/blue/violet gradient, minimal dimensional highlight. More precise and graphic than a 3D sculpture.  
> Background: fully transparent alpha, suitable on navy and white.  
> Constraints: no lettering, wordmark, shield, lock, outer border, tile, container, complex leaf or butterfly shape, glow halo, fine line details, watermark. Use four thick strokes maximum.
